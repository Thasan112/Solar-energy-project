# Solar-energy-project
 Financial Performance &amp; Investment Decision Dashboard


## 📊 Overview
This project delivers a Power BI dashboard connected to a MySQL database to analyze global real estate investment performance by region and city.

## 🚀 Features

- Average Price by Region
- ROI % by City
- ROI Ranking by Region
- Investment Efficiency
- Payback Risk Distribution
- Annual Production by GHI
- Total Installation of Solar energy euipments by Region and Country
- Average Annual Solar energy by Country
- Savings Reliabilit Score b Region
- Sunlight Hours vs Region
- Sustainability and environmental Impact factors like Co2 reduction by Country and City ,ROI Vs Solar Viability
- Interactive filtering in Power BI
- Matrix Visual
- Map VIsual

## 🏗 Architecture

MySQL Database → Analytical Views → Power BI Dashboard

## 🛠 Tech Stack

- MySQL 8+
- Power BI Desktop
- SQL Views
- DAX Measures
